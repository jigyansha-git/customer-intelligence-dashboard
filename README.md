# Customer Intelligence & Retention Dashboard

##  Project Overview
This project analyzes customer behavior in an e-commerce dataset to identify high-value customers and detect churn risk.

##  Objectives
- Understand customer spending patterns
- Segment customers based on value
- Identify churn-risk customers
- Provide business recommendations

##  Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Power BI

##  Key Insights
- High-value customers contribute most of the revenue
- Customers inactive for long periods show reduced spending
- Membership type influences customer behavior
- A small percentage of customers are at risk of churn

##  Dashboard Features
- KPI metrics (Revenue, Customers, Avg Spend)
- Customer segmentation analysis
- Retention & churn risk analysis
- Interactive filters

## 🚀 Conclusion
This dashboard helps businesses understand customer behavior and take data-driven actions to improve retention and revenue.
